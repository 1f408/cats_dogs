# インクルード拡張について

cats\_dogsのインクルード拡張は、外部のMarkdownファイルをInline要素として取り込む拡張機能です。  
図や表などのデータが大きな要素を別ファイルに分割したり、別のMarkdownファイルと同じコンテンツを共有したりするために実装したものです。

## 構文

以下の[MS Learn インクルード構文]と同じ書式に対応しています。  

```md
[!INCLUDE [<title>](<filepath>)]
```

この書式で、`<filepath>`のパスで指定されたのMarkdownファイルの内容を組み込みます。
ただ、MS Learnの実装では特殊なパスの処理をするため、このパスの処理に互換性がありません。

## 注意点

インクルードされるファイルの内容は、インクルードするファイルの`ETag`ヘッダーには反映しません。  
このため、インクルードされるファイルだけ更新しても、HTTPキャッシュは自動では更新されません。
HTTPキャッシュの更新が必要であれば、強制再読み込みなどで強制的に更新してください。

## エラー処理

以下の条件でインクルードを中止して、構文の`<title>`部分の内容を出力します。

1. ファイルが読み取れなかった。
2. Markdownファイル(拡張子で判定)ではない。
3. インクルード先で同じファイルを再度インクルードしている。(無限ループ回避)
4. インクルードを過剰に繰り返している。

構文の`<title>`部分にはインラインのMarkdownが記述できるので、以下のようなにエラー時はリンクになる記述もできます。

```md
[!INCLUDE [[リンクタイトル](include.md)](include.md)]
```
