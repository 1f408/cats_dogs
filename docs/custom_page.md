# カスタムページ機能

カスタムページ機能で、サイト全体またはページ毎に、以下の要素をカスタマイズできます。

- ページタイトル(HTMLのtitleタグの内容)
  - 自動で設定されるページタイトル以外のタイトルへ変更したい時に利用します。
- Markdown書式の仕様
  - 異なるMarkdown仕様のファイルを扱いたい時に利用します。
- ページ位置のナビの表示の表示非表示
  - ページ位置のナビが邪魔なページなどで利用します。
- ディレクトリビューの表示の制御方法
  - ディレクトリビューが邪魔なページなどで利用します。
- ページスタイル
  - ページスタイル名を指定する事で、見た目を変更可能です。ページスタイルが別途必要です。
- ソーシャルメディアカード機能
  - X.comなどの共有カード情報をページに埋め込む機能です。
- 印刷用紙の利用方法
  - 印刷時の用紙サイズや印刷時の縮尺(zoom率)が変更できます。
  - 印刷時だけ(文字や絵などの)縮尺印刷したい時、印刷用紙を指定したい時などに利用します。　

## サイト全体のカスタマイズ

[カスタムページ機能の設定ファイル](custom_page_conf.md)を使うことで、サイト全体のデフォルト値が設定可能です。  
デフォルト値の変更でサイト全体がカスタマイズされますが、デフォルト値よりページ毎の設定が優先されるので、ページ毎のカスタマイズも可能です。

## ページ毎のカスタマイズ

ファイルの先頭へFront Matterの形式で、カスタマイズ内容を記述することでページ毎のカスタマイズが行えます。  
Front Matterは以下の例のように、区切り文字列の行(YAMLの場合は`---`)で挟んで、ファイルの先頭部分へ記述します。

```
---
product: cats
title: Page title
location_navi: none
directory_view_mode: none
paper_style: A4
---
# サンプル 

以下のカスタマイズをするサンプルです。

- ページタイトルの指定
- ページ位置のナビの表示の非表示
- ディレクトリビューの表示の非表示
- 印刷用紙にA4を指定
```

デフォルト設定ではYAML front matterのみ処理しますが、設定変える事で以下のFront Matterにも対応します。

- YAML front matter(`---`が区切り文字列)
- TOML front matter(`+++`が区切り文字列)
- JSON front matter(`;;;`が区切り文字列)

ページ個別のカスタマイズ設定については、[ページ個別設定用のFront Matter](front_matter.md)の説明を参照してください。  
カスタムページ機能全体の設定については、 [カスタムページ機能の設定ファイル](custom_page_conf.md)の説明を参照してください。
